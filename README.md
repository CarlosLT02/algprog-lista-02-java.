## 🧠 Exercícios

### ✅ 1. Número Informado

**Descrição:**
O programa solicita um número ao usuário e exibe a mensagem:

```
O número informado foi [número]
```

**Objetivo:**
Treinar entrada de dados e saída no console.

---

### ✅ 2. Operações Matemáticas

**Descrição:**
O programa solicita dois números e realiza:

* Soma
* Subtração
* Multiplicação

**Saída esperada:**

```
Soma: X
Subtração: Y
Multiplicação: Z
```

**Objetivo:**
Praticar operações matemáticas básicas.

---

### ✅ 3. Média de Notas

**Descrição:**
O programa solicita 4 notas bimestrais e calcula a média.

**Fórmula:**

```
média = (nota1 + nota2 + nota3 + nota4) / 4
```

**Objetivo:**
Trabalhar com múltiplas entradas e cálculos simples.

---

### ✅ 4. Cálculo de Combustível

**Descrição:**
O programa solicita:

* Preço do litro da gasolina
* Quantidade de litros vendidos

E calcula o valor total a ser pago pelo cliente.

**Fórmula:**

```
total = preço * litros
```

**Objetivo:**
Aplicar cálculos em situações do dia a dia.

---

### ✅ 5. Viagem Eurotrip

**Descrição:**
O programa solicita o valor de uma viagem “Eurotrip” com destino a:

1. Alemanha
2. Portugal
3. Itália

Pode ser usado para:

* Exibir o valor total
* Ou dividir o custo entre amigos

**Objetivo:**
Simular um cenário real envolvendo planejamento financeiro.
